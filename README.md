# homebrew-nauterm

Homebrew Cask for [Nauterm](https://github.com/korvect/nauterm) — a modern cross-platform terminal and remote access workspace for SSH, Mosh, Telnet, serial, SFTP, port forwarding, snippets, and encrypted sync.

## Installation

```bash
brew tap korvect/nauterm
brew install --cask nauterm
```

or directly:

```bash
brew install --cask korvect/nauterm/nauterm
```

## Upgrading

```bash
brew upgrade --cask nauterm
```

## Uninstallation

```bash
brew uninstall --cask nauterm
```
